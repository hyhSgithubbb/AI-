# 윷판 한마당

브라우저에서 바로 하는 윷놀이 게임입니다. `index.html`을 브라우저로 열면 됩니다 (설치 필요 없음).

## 기능
- 29칸 전통 윷판 (모·뒷모·찌모·참먹이·방, 지름길 포함)
- 2~4팀 선택, 팀당 말 4개
- `윷 던지기` 버튼: 윷가락 4개가 던져지는 애니메이션 후 결과(도·개·걸·윷·모·빽도)를 크게 표시
  - 표시된 윷가락 하나만 젖혀지면 빽도
- 윷·모, 상대 말 잡기 시 한 번 더 던지기
- 같은 팀 말끼리 업기(함께 이동), 상대 말 잡기(잡힌 말은 대기석으로 복귀)
- 말 위에 마우스를 올리면 도착 칸 미리보기

## 한가위 테마 · 연출
- 보름달 속 떡방아 찧는 달토끼, 송편 모양 말(분홍·쑥·호박·자색송편), 떡살 무늬 모서리 칸
- 상대 말을 잡을 때: 조준경 락온 → 총성·히트마커·화면 흔들림·섬광·파편, 킬피드, 더블/트리플 킬, 잡힌 송편이 대기석으로 날아감
- 효과음과 배경음은 모두 Web Audio로 직접 합성 (외부 음원 없음)
  - 배경음: 평조 5음 가야금풍 선율 + 세마치 장구 장단
  - 오른쪽 위 `배경음` / `효과음` 버튼으로 끄고 켤 수 있음 (브라우저 정책상 첫 클릭 후 재생)

## 규칙 메모
- 모(오른쪽 위)·뒷모(왼쪽 위) 모서리나 방(가운데)에 **멈추면** 지름길로 들어갑니다. 방에 멈춘 말은 참먹이 방향으로 갑니다.
- 참먹이(출발점)에 닿거나 지나가면 완주입니다.
- 빽도는 한 칸 뒤로 이동하며, 판 위에 말이 없으면 무효입니다.
