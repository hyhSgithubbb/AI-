# 윷판 한마당

브라우저에서 바로 하는 윷놀이 게임입니다. 설치할 것은 없습니다.

```bash
python3 -m http.server 8000   # 그다음 http://localhost:8000 접속
```

`index.html`을 파일로 바로 열어도 게임은 되지만, 유튜브 배경음은 웹 서버(http://)로 열어야 재생됩니다.

## 조작
- 시작하면 팀 수(2~4)와 팀별 닉네임을 정하는 창이 뜹니다. `새 게임` 버튼으로 언제든 다시 열 수 있습니다.
- 힘 게이지가 계속 움직입니다. 원하는 위치에서 **스페이스바**(또는 `윷 던지기` 버튼)를 누르면 윷이 던져집니다.
  - 게이지 구간 길이 = 일반 35 | 위험 10 | 황금 10 | 위험 10 | 일반 35 (위험·황금이 정중앙) (왕복 1초)
  - 일반: 실제 윷 확률(낙 5%) / 황금: 걸·윷·모가 잘 나옴(낙 1%) / 위험: 낙 20%
  - 낙(落): 윷가락이 멍석 밖으로 떨어져 그 던지기는 무효
- 결과는 화면 가운데 큰 창으로 뜹니다 (클릭이나 스페이스바로 바로 닫기).

## 배경음
- 기본: 유튜브 곡 `l-vSSYEuO88` 53초부터 반복 재생 (오른쪽 위 작은 공식 플레이어)
- 유튜브를 불러올 수 없는 환경(파일로 직접 열기, 임베드 차단 등)에서는 가야금·장구 합성 배경음으로 자동 전환
- `음악 파일` 버튼으로 내 컴퓨터의 음악 파일을 배경음으로 쓸 수도 있습니다.

## 기능
- 29칸 전통 윷판 (모·뒷모·찌모·참먹이·방, 지름길 포함)
- 2~4팀 선택, 팀당 말 4개
- `윷 던지기` 버튼: 윷가락 4개가 던져지는 애니메이션 후 결과(도·개·걸·윷·모·빽도)를 크게 표시
  - 표시된 윷가락 하나만 젖혀지면 빽도
- 윷·모, 상대 말 잡기 시 한 번 더 던지기
- 같은 팀 말끼리 업기(함께 이동), 상대 말 잡기(잡힌 말은 대기석으로 복귀)
- 말 위에 마우스를 올리면 도착 칸 미리보기

## 한가위 테마 · 연출
- 보름달 속 떡방아 찧는 달토끼, 송편 모양 말(분홍·쑥·호박·자색송편), 떡살 무늬 모서리 칸
- 상대 말을 잡을 때: 조준경 락온 → 총성·히트마커·화면 흔들림·섬광·파편, 킬피드, 더블/트리플 킬, 잡힌 송편이 대기석으로 날아감
- 효과음과 배경음은 모두 Web Audio로 직접 합성 (외부 음원 없음)
  - 배경음: 평조 5음 가야금풍 선율 + 세마치 장구 장단
  - 오른쪽 위 `배경음` / `효과음` 버튼으로 끄고 켤 수 있음 (브라우저 정책상 첫 클릭 후 재생)

## 규칙 메모
- 모(오른쪽 위)·뒷모(왼쪽 위) 모서리나 방(가운데)에 **멈추면** 지름길로 들어갑니다. 방에 멈춘 말은 참먹이 방향으로 갑니다.
- 참먹이(출발점)에 딱 맞게 도착하면 그 칸에 머무르고, 참먹이를 **지나가야** 완주입니다. 참먹이에 서 있는 말은 다음에 한 칸이라도 나가면 완주합니다.
- 빽도는 한 칸 뒤로 이동하며, 판 위에 말이 없으면 무효입니다.
